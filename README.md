# Reassessing Hyperparameter Optimization for Cancer Classification: A Leakage-Free, Multi-Run Comparison of Grid, Random, and Bayesian Search on Small Imbalanced Datasets

## A Leakage-Free, Multi-Run Statistical Benchmark on Small and Imbalanced Cancer Datasets

This repository contains the supplementary materials and reproducible computational code associated with the manuscript:

**"Reassessing Hyperparameter Optimization for Cancer Classification: A Leakage-Free, Multi-Run Comparison of Grid, Random, and Bayesian Search on Small Imbalanced Datasets"**

The repository provides the supplementary quantitative results and computational workflow supporting the analyses reported in the manuscript.

---

## Study Overview

This study systematically evaluates whether conventional hyperparameter optimization (HPO) strategies provide meaningful performance improvements for machine-learning classification on small and imbalanced cancer datasets.

Four hyperparameter strategies were compared:

- No-Tuning (default hyperparameters)
- Grid Search
- Random Search
- Bayesian Optimization

Four machine-learning classifiers were evaluated:

- XGBoost
- Random Forest
- Support Vector Machine (SVM)
- LightGBM

The experiments were conducted on three heterogeneous cancer datasets:

- Lung Cancer
- Breast Cancer Wisconsin
- Cervical Cancer

The experimental design comprised **3 datasets × 4 classifiers × 4 tuning strategies = 48 configurations**, with **10 independent runs and 5-fold stratified cross-validation** for each configuration.

---

## Leakage Prevention

To minimize the risk of data leakage, preprocessing and SMOTE oversampling were performed exclusively within the training folds using an `imblearn.Pipeline`.

The evaluation design ensured that:

1. Transformation parameters were fitted only using training data.
2. Synthetic samples generated by SMOTE did not cross validation boundaries.
3. The same train/test splits were used across tuning strategies within each run, enabling paired statistical comparisons.

---

## Statistical Analysis

The study evaluates differences between tuning strategies using:

- Friedman omnibus test
- Wilcoxon signed-rank post-hoc tests
- Bonferroni correction
- Effect-size estimation (`r = Z / √N`)
- 95% confidence intervals
- Multi-run performance analysis

The study also evaluates computational cost using runtime and F1-score efficiency measures.

Model interpretability was assessed using SHAP for tree-based models.
