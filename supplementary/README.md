# Supplementary Materials

This directory contains the supplementary materials supporting the manuscript.

## Supplementary Files

- S1_supp_summary_all48.csv — Summary results for all 48 experimental configurations.
- S2_supp_ci_table.csv — 95% confidence interval analysis.
- S3_supp_effectsize_full.csv — Statistical comparison and effect-size analysis.
- S4_supp_raw_10runs.csv — Raw F1-score results from 10 independent runs.
- S5_ranking_per_config.csv — Ranking of experimental configurations.
- S6_supp_cost_benefit.csv — Computational cost-benefit analysis.

These files provide the detailed quantitative results supporting the analyses reported in the manuscript.
